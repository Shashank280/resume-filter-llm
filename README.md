# Resume Filter Using LLM 🚀🚀 


This is a basic Resume filter and my first project I have made using LLM. 🤖🤖

## Why I built this Project 🔥
🤞Manually opening hundreds of applicants' resumes is time consuming and so this will do this work easily even with 100s of resumes just once.

## What Output it will give?

It will give you a list of two top and bottom two candidates with its score matching with the job description between 0 to 100 and which is not just a guess it will be
100% by the match and also their skills what they have.

# Step by Step Guide ⏬⏬

## 1. Create a directory (normal folder) named let's take "Project" and then copy this "filter.py".
## 2.  Then get a Groq Api key from Groq Developer console and paste it in the text editor with writing like 

### GROQ_API_KEY= "Your Api key directly without anything" 🔥
And save it as .env file inside the same "Project" file.

## 3. Now after that just make another sub folder named "resumes" where you will store all the 1000s of resumes under the same folder "Project". 🔥

## 4. Now just move in any code editor and in the same folder "Project" Do these steps to install some of the commands:

🚀🚀🚀📚📚

### 1. Install Venv by {uv venv}
### 2. Then activate virtual environment by {.\.venv\Scripts\activate}
### 3. now install some required libraries by {uv pip install python-dotenv pydantic groq python-docx pypdf}


# Solid note you must not change the variable name for Api linkage and the resume name it should be the same as you made a sub folder in "Project".
